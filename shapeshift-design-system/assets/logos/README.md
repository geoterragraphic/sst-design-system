# Logos
- `logo-horizontal.png` — primary logo, 1500 × 600 transparent PNG. Headers, document title blocks, slide footers, wide layouts. Minimum 120px (30mm) wide.
- `logo-stacked.png` — emblem above wordmark, 1200 × 920 transparent PNG. Covers, title slides, square social tiles. Minimum 80px (20mm) wide.
Full colour only (near-black wordmark, `ss-cyan` "TECHNOLOGIES", silver-grey emblem). Place on `ss-white` or `ss-mist`; never on `ss-navy`, dark grounds or busy photos. Never redraw, recolour, stretch or add effects.
