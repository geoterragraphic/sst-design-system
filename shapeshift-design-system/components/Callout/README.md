# Callout
A quiet panel for an aside in articles and documents: `ss-mist` ground, 1px `ss-cyan` left edge, `ss-2` × `ss-3` padding.

- Markup: `<div class="ss-callout">`; add `ss-callout--note` (`ss-paper` ground) or `ss-callout--warning` (`ss-warning-bg`, `ss-warning-edge`, `ss-warning-ink`). The consumer provides the text.
- Start a warning with the word "Warning" so meaning never rests on colour alone.
- Don't: thick coloured edges, icons in emoji, stacking more than two in a row.
