# NavyBand
A full-width `ss-navy` section for emphasis, with `ss-7` padding.

- Markup: `<section class="ss-band">`; the consumer provides a label, heading, body and an optional action button.
- Headings `ss-white`; body `ss-on-navy-body`; small accents and labels `ss-light-cyan`; focus outline white.
- Don't: place the logo on it, use `ss-cyan` for small text on it, or nest a second dark band.
