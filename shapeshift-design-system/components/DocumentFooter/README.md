# DocumentFooter
The running footer for documents: the horizontal logo or company details on the left, the trust badges on the right, bottom-aligned.

- Ask the user first whether to include badges, and which. The consumer provides that choice and any company details.
- Badges: ISO 9001 then GRCA, `ss-4`–`ss-5` apart, 12–15mm tall in A4 (about 45–60px on screen), never taller than the logo.
- White ground only. Use on the first page and/or the running footer, never both header and footer.
- Don't: use it on social posts or blog articles, add claims next to the badges, recolour or crop either badge.
